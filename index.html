[ HOW TO USE ]

PANDUAN NAVIGASI
  1. Gunakan tombol [ SEARCH ] di pojok kiri atas untuk mencari nama kecamatan secara lengkap.
  2. Gunakan panel [ LAYERS ] di kanan atas untuk beralih peta dasar (OSM / Satelit Esri) dan menyalakan/mematikan data spasial.
  3. Klik titik, garis, atau wilayah polygon untuk membuka jendela informasi spasial (*popup*).
  4. Pilih menu [ UNDUH DATA ] pada Navbar untuk mengunduh berkas GeoJSON.

[ ABOUT MAP ]

DESKRIPSI

Aplikasi WebGIS ini menyajikan informasi spasial Kabupaten Flores Timur. Peta interaktif ini memaparkan sebaran toponimi, jaringan jalan, serta kepadatan penduduk per kecamatan menggunakan teknik pemetaan khoroplet.

DATA LAYER
  • [POINT] TOPONIMI: Titik lokasi penting
  • [LINE] JALAN: Jaringan jalan wilayah
  • [POLYGON] PENDUDUK: Kepadatan penduduk per kecamatan
